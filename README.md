# Bordeaux — Guide des Grands Vins

Migriert von attallah.de-Server (Strato), Ordner `Bordeaux`.
Live via GitHub Pages: https://dattallah.github.io/bordeaux-weine/

## Versionierung
Design und Aufbau wie der Schwester-Guide [Südafrika](https://attallah.de/suedafrika/) (mobile-first, Tab-Leiste, Dunkelmodus).
Bei jeder Änderung einen Eintrag oben in `changelog` (in `index.html`) ergänzen. Die Nummer erscheint oben rechts in der App.
Die Versionsnummer auf der Projektkarte in [attallah.de](https://github.com/dattallah/attallah-de) (`index.html`, `card-ver`) mitziehen.
